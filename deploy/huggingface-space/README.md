# 📝 Text Summarizer — T5 Transformer

Fine-tuned T5 transformer for text summarization, trained on the SAMSum dataset. Paste any text (chat, article, notes) and get a concise summary in real time.

Full training details, architecture, and code: [GitHub repo](https://github.com/Harivansh124/T5-Text-Summarizer-SAMSum)
